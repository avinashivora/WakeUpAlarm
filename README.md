# ⏰ Wake Up

> A personalized alarm app that automates the process of setting daily alarms based on when you need to leave and how long you need to get ready.

Setting multiple alarms every day became a repetitive task. Wake Up turns that routine into an automated workflow — provide the time you need to leave and the time required to get ready, and the app calculates and schedules the alarms for you.

Because apparently, one alarm is never enough. 😄

---

## ✨ Features

- ⏰ **Automated Alarm Scheduling** — Calculate and schedule alarms based on your routine.
- 🚗 **Departure-Time Based** — Start with the time you need to leave rather than manually calculating when to wake up.
- 🕐 **Preparation-Time Calculation** — Account for the time needed to get ready.
- 🔔 **Multiple Alarms** — Automatically create the required sequence of alarms in your system's clock application.
- 📅 **Daily Routine Automation** — Reduce repetitive alarm setup.
